## Claude-specific workflow

Use the shared project instructions as the primary source
of engineering rules.

For architecture discussions:
- Prefer analysis before implementation.
- Explain alternatives and trade-offs.
- Do not edit files unless explicitly requested.

For implementation:
- Respect the approved scope.
- Follow existing project conventions.
- Run relevant quality checks.

For code review:
- Prioritize correctness, regressions, and security.
- Report actionable findings with file references.
- Do not modify files during review.
