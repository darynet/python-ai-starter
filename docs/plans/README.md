
# Implementation Plans

This directory contains implementation plans for
non-trivial features and refactoring tasks.

## Naming Convention

Use descriptive filenames:

- `commit-message-generation.md`
- `authentication-refactoring.md`
- `database-migration.md`

## Plan Lifecycle

1. Draft
2. Reviewed
3. Approved
4. In Progress
5. Completed

## Guidelines

Each plan should contain:

- Goal
- Context
- Scope
- Implementation tasks
- Acceptance criteria
- Verification steps
- Risks
- Open questions

Plans should be small enough to review and execute
incrementally.

Do not treat draft plans as approved implementation instructions.

Keep completed plans as historical records when useful.
